# Gen1Recomp-Italian-Translation

Questa è una mod di traduzione in lingua italiana per il progetto **Gen 1 Recomp**. 
*Nota: Questa repository contiene esclusivamente i file testuali di localizzazione (script Lua e manifest) e NON include alcun asset originale, ROM o codice sorgente del gioco base o dell'emulatore.*

## Stato della Traduzione
- Menu e Interfaccia: In corso
- Dialoghi: In corso
- Strumenti e Mosse: In corso

## Installazione (Android)
1. Scarica l'ultimo file `.zip` disponibile nella sezione **Releases** di questa repository.
2. Trasferisci il file `.zip` sul tuo dispositivo Android.
3. Avvia Gen 1 Recomp.
4. Apri il menu delle Mod (icona a griglia vicino al pulsante 'Y').
5. Seleziona **Import mod.zip**, cerca il file scaricato e attivalo.

## Installazione (Windows / Mac / Linux)
1. Scarica l'ultimo file `.zip` disponibile nella sezione **Releases** di questa repository.
2. Apri la cartella di installazione o la cartella dei dati utente di Gen 1 Recomp sul tuo computer.
3. Trova la sottocartella `mods` (se non esiste, creala).
4. Inserisci il file `.zip` (senza estrarlo) all'interno della cartella `mods`.
5. Avvia il gioco e abilita la mod dal menu delle opzioni.
